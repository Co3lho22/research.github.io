Coverage-Guided Fuzzer

ongoing
fuzzing binary-analysis c

Overview

Building a coverage-guided fuzzer inspired by AFL and libFuzzer. The goal is to understand fuzzing internals deeply and create tooling optimized for binary exploitation research.

Motivation

  • Understand coverage-guided fuzzing mechanics at the implementation level
  • Implement custom mutation strategies for binary protocols
  • Target vulnerability classes relevant to research: buffer overflows, format strings, UAF

Status

Work in progress. Source available on GitHub.
